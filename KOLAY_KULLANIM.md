## 2.1 Kolay Kullanım

Annenin ve teknik ayarlarla uğraşmak istemeyen herkesin kolay kullanması için uygulamada **yalnızca bir ekran** bulunur:
1. YouTube'da bağlantıyı kopyala; **1 · BAĞLANTIYI YAPIŞTIR** düğmesine bas.
2. **2 · MP3 İNDİR** düğmesine bas.
3. Aynı ekrandaki **3. İndirilen müziklerim** bölümünden **Dinle** düğmesine bas.

Kalite otomatik **192 kbps hedefi** olarak seçilir; ses kalitesi kaynağın üzerinde artırılamaz. Sunucu adresi, API anahtarı ve gelişmiş ayarlar görünmez. Dosyalar cihazda Download/LinkMP3 konumunda kalır. V2.1, farklı Android sürümlerinde arşivin boş görünmesine karşı kayıt URI'lerini kalıcı olarak tutar. Otomatik Android emülatör testi MP3 kaydetme, listeleme, dosyayı okuma ve silmeyi sınar.

Paket kimliği v2.0 ile aynıdır: com.kadir.linkmp3.pro. GitHub Actions debug imzaları koşular arasında değişebilir; cihaz "Uygulama yüklenemedi" derse önceki debug sürümünü kaldırmak gerekebilir. Daha önce indirdiğiniz MP3'lerin silinmesini istemiyorsanız önce Dosyalarım üzerinden Download/LinkMP3 klasöründeki dosyaları yedekleyin. Kalıcı release imzası için GitHub'da güvenli saklanan bir keystore gerekir.
